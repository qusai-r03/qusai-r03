## Featured Projects

### Rydora — Smart Shuttle Platform

A shuttle coordination platform built for 42 Irbid.

* Student, driver, and administrator dashboards
* Smart grouping of compatible booking requests
* Live trip and bus tracking
* Dynamic station management
* Seat confirmation and passenger handling
* Firebase Authentication and Firestore integration

**Technologies:** React, Vite, Firebase, JavaScript, Leaflet, OpenStreetMap

---

### Pac-Man: Phantom Protocol

A configurable Pac-Man game built with Python and Pygame.

* Object-oriented game architecture
* Multiple ghost movement strategies
* Chase, patrol, frightened, and eaten states
* Scoring, lives, levels, and high-score management
* JSON-based game configuration
* Keyboard controls and developer cheat mode

**Technologies:** Python, Pygame, OOP, JSON

---

### Inception

A secure multi-container infrastructure developed as part of the 42 Common Core.

* Custom Docker images based on Debian
* NGINX with TLS 1.2 and TLS 1.3
* WordPress with PHP-FPM
* MariaDB database
* Docker Compose orchestration
* Persistent volumes and Docker secrets
* Isolated internal network

**Technologies:** Docker, Docker Compose, NGINX, WordPress, MariaDB, Bash

---

### Push Swap

An algorithmic sorting project that sorts integers using two stacks and a restricted set of operations.

* Adaptive algorithm selection
* Sorting for small input sets
* Chunk-based sorting
* Binary radix sort
* Disorder measurement
* Benchmark and operation-count analysis

**Technologies:** C, Algorithms, Data Structures, Make

---

### ft_printf

A custom implementation of the C `printf` function.

* Variadic function handling
* Character and string formatting
* Signed and unsigned integer conversion
* Hexadecimal and pointer formatting
* Static library generation

**Technologies:** C, Variadic Functions, Make

---

### get_next_line

A C function that reads a file descriptor one line at a time.

* Static variable management
* Configurable buffer size
* Memory-safe string operations
* Support for files and standard input
* Multiple file-descriptor handling

**Technologies:** C, File Descriptors, Memory Management
